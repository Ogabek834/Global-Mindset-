# Global Mindset — Starter

This repository is a starter for the Global Mindset site (bilingual: English / Uzbek).
It includes Next.js + TypeScript + Tailwind + TinaCMS (git-based) skeleton.

How to run locally:
1. npm install
2. npm run dev
3. Open http://localhost:3000
